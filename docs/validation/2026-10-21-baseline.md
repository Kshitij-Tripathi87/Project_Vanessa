## 3. Four P0 Issues Addressed

### P0 1: Development Startup Voice Service Inclusion
- **Resolution**: Added `@vanessa/voice-agent` to root `package.json` concurrent `dev` script (`dev:voice`), and established `pnpm readiness` script to probe all 4 services with real health endpoints.
- **Verification**: `pnpm readiness` returns exit code 0 with 4/4 services online.

### P0 2: Fish Audio Provider Defaulting & Transparency
- **Resolution**:
  - `voiceSession.ts` now defaults both ASR and TTS to `"fish"` (`VOICE_ASR_PROVIDER=fish`, `VOICE_PROVIDER=fish`).
  - Added session lifecycle management (`activateStream` / `deactivateStream`) in `FishAsrAdapter`: connects WebSocket only during active wake sessions and automatically disconnects on idle timeout (25s), preserving zero-budget economics against cloud stream charges ($0.36/hr).
  - Explicit credential and fallback visibility: If `FISH_API_KEY` is missing or unauthenticated, it clearly reports that fallback to local Faster-Whisper is engaged per policy, rather than silently masquerading.

### P0 3: Headless Subprocess Verification (Terminal Launch != Test)
- **Resolution**:
  - `TestingAgent` headlessly invokes test subprocesses (`pnpm --filter @vanessa/incident-lab test`), captures stdout/stderr, and strictly asserts `exitCode === 0`.
  - Launching Windows Terminal or PowerShell is treated purely as a workspace initiation action, explicitly rejected as proof of test completion.

### P0 4: Process-Level Fault Injection Drills
- **Resolution**:
  - Created `evals/drills/processFailureDrills.test.ts` executing real process kills, real SQLite durability checks, real failing child processes (`exit 1`), and emergency kill switch cancellation emitting `task.cancelled`.
  - Added to root `test:drills:process` and included in `test:all`.
